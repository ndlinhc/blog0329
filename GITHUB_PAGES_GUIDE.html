如何将博客网站部署到 GitHub Pages

GitHub Pages 是免费的静态网站托管服务，非常适合博客网站。

下载博客网站文件

你可以下载以下文件包进行上传：

  • blog-github-pages.tar.gz - 静态博客网站完整包
  • blog0329.tar.gz - 带权限管理的完整博客系统

步骤1: 访问GitHub

登录 GitHub: https://github.com

导航到你的仓库: ndlinhc/blog0329

步骤2: 上传文件

在仓库页面:

  1. 点击 "Add file" → "Upload files"
  2. 选择要上传的文件
  3. 点击 "Commit changes"

你需要上传的文件:

  • index.html
  • about.html
  • contact.html
  • deploy.html
  • README.md
  • css/目录下的所有.css文件
  • js/目录下的所有.js文件
  • blog/目录下的所有.html文件

步骤3: 配置GitHub Pages

  1. 点击 "Settings"
  2. 左侧找到 "Pages"
  3. 在 "Source" 部分，选择 "Deploy from a branch"
  4. 选择分支 "main"
  5. 选择文件夹 "/" (根目录)
  6. 点击 "Save"
GitHub Pages将在几分钟内自动部署你的网站
访问地址: https://ndlinhc.github.io/blog0329

步骤4: 验证部署

等待大约5分钟后:

  1. 访问 https://ndlinhc.github.io/blog0329
  2. 如果看到博客首页，说明部署成功
  3. 如果未显示，可能需要更多时间

常见问题:

  • 确保 index.html 文件在根目录
  • 确保所有CSS和JS文件路径正确
  • 如果部署失败，检查文件结构是否正确

GitHub Pages的优点

  • 免费: GitHub Pages完全免费
  • 自动部署: 每次推送代码都会自动更新
  • SSL证书: 自动提供HTTPS加密
  • CDN: 全球内容分发网络，访问速度快
  • 简单配置: 只需要几分钟即可完成设置

注意事项

  • GitHub Pages只支持静态网站（HTML/CSS/JavaScript）
  • 不支持服务器端代码（PHP、Node.js等）
  • 单个文件最大100MB
  • 每月流量限制100GB

备用部署方案

如果需要部署带权限管理的完整博客系统（包含Node.js后端），请使用:

  • Vercel: https://vercel.com
  • Heroku: https://heroku.com
  • Netlify: https://netlify.com

下载 blog0329.tar.gz 包含完整项目。

立即开始部署

你现在可以:

  1. 下载 blog-github-pages.tar.gz
  2. 解压缩文件
  3. 上传到 GitHub 仓库 blog0329
  4. 配置 GitHub Pages

开始部署后，访问:

https://ndlinhc.github.io/blog0329
