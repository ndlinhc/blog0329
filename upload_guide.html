博客网站上传指南

📱 方案1: GitHub网页上传（推荐）

步骤1: 登录GitHub

访问: https://github.com

登录你的账号

步骤2: 进入仓库

访问: https://github.com/ndlinhc/blog0329

可以看到blog0329仓库页面

步骤3: 上传文件

  1. 点击右上角的 "Add file" 按钮
  2. 选择 "Upload files"
  3. 选择 blog-github-pages.tar.gz 中的所有文件
  4. 点击 "Commit changes"

步骤4: 配置GitHub Pages

  1. 点击 "Settings"
  2. 左侧菜单找到 "Pages"
  3. 在 "Source" 部分，选择 "Deploy from a branch"
  4. 选择分支 "main"
  5. 选择文件夹 "/" (根目录)
  6. 点击 "Save"
完成! 网站会自动部署到:
https://ndlinhc.github.io/blog0329

💻 方案2: Git命令行上传

注意: 需要GitHub token有repo权限

步骤1: 配置Git认证

git config --global credential.helper store echo "https://ndlinhc:YOUR_GITHUB_TOKEN@github.com" > ~/.git-credentials

步骤2: 配置用户信息

git config --global user.name "ndlinhc" git config --global user.email "ndlinhc@example.com"

步骤3: 推送代码

git push https://github.com/ndlinhc/blog0329.git main

🔧 方案3: 生成新的GitHub token

步骤1: 生成新token

  1. 访问: https://github.com/settings/tokens
  2. 点击 "Generate new token"
  3. 输入名称: blog0329-upload
  4. 选择权限: "repo" (全部权限)
  5. 点击 "Generate token"
  6. 复制新token

步骤2: 使用新token

echo "https://ndlinhc:NEW_TOKEN@github.com" > ~/.git-credentials git config --global credential.helper store git push https://github.com/ndlinhc/blog0329.git main
